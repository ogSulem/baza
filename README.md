# Telegram-бот + Google Таблицы: поставщики и заказчики

Бот сопоставляет **заказчиков** и **поставщиков** по **категории** (колонка «Назначение» из прайса) и **городу**.

Исходные данные: `Поставщики общий список.xlsx` (формат № / Материал / Назначение / Товар / Стоимость / контакты).

## Нормализованная таблица (для Google)

Три листа в одной Google-таблице:

| Лист | Назначение |
|------|------------|
| **Поставщики** | город, регион, категория, имя, телефон, ссылка, telegram_user_id |
| **Заказчики** | регистрации из бота |
| **Категории** | список кнопок в боте (= уникальные «Назначение» из прайса) |

### Шаг 1 — сгенерировать файл из xlsx

```bash
pip install -r requirements.txt
python scripts/export_normalized.py --in "Поставщики общий список.xlsx" --out data/normalized_for_google.xlsx
```

Откройте `data/normalized_for_google.xlsx` и **импортируйте в Google Таблицу** (или загрузите каждый лист на отдельный лист вручную).

### Шаг 2 — Google API (автозагрузка)

1. [Google Cloud Console](https://console.cloud.google.com/) → Service Account → JSON-ключ → файл `credentials/google-service-account.json`
2. Создайте Google Таблицу, **дайте доступ на редактирование** email сервисного аккаунта
3. Скопируйте ID таблицы из URL в `.env`:

```env
GOOGLE_SPREADSHEET_ID=ваш_id_таблицы
GOOGLE_CREDENTIALS_JSON=credentials/google-service-account.json
```

```bash
python scripts/push_to_google.py --in "Поставщики общий список.xlsx"
```

## Запуск бота

```env
BOT_TOKEN=...
ADMIN_IDS=123456789
GOOGLE_SPREADSHEET_ID=...
GOOGLE_CREDENTIALS_JSON=credentials/google-service-account.json
```

```bash
python main.py
```

- С **Google Таблицей**: поставщики/заказчики/категории читаются и пишутся в Sheets; сессии — в SQLite
- **Без Google**: только SQLite (как раньше), категории по умолчанию: Пилорама, Доски, …

## Поведение бота

| Роль | Действие |
|------|----------|
| **Поставщик** | Телефон → город → категория → запись в лист «Поставщики» + «Вы записаны…» |
| **Заказчик** | Телефон → город → категория → список поставщиков из таблицы (сначала свой город) + запись в «Заказчики» |

Категории в боте = лист **«Категории»** (из «Назначение»: *Каркас домов и дорогих бань*, *Фундамент*, *Обшивка стен*, *Окна/Двери*, …).

Город для импорта из прайса: из заголовка *«Каркас Барнаул»*, *«Каркас Алтайский край»* → **Барнаул** и т.д.
